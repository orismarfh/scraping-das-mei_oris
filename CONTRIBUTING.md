# Contribuindo

1. Abra uma issue descrevendo o problema ou nova funcionalidade.
2. Crie um branch:
   - `feat/<nome>` para novas features
   - `fix/<nome>` para correções
3. Faça commit e push:
   ```bash
   git add .
   git commit -m "feat: descrição curta"
   git push origin <branch>
